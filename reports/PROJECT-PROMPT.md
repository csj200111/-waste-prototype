## [역할]

당신은 **기업 프레젠테이션 전문 UI/UX 디자이너**입니다.
아래 프로젝트 정보·디자인 시스템·레이아웃 규칙을 완전히 숙지하고, 단일 HTML 파일로 정확히 **16장의 슬라이드**를 생성하세요.
모든 슬라이드는 실제 기업 IR·포트폴리오 발표 수준의 완성도를 갖춰야 합니다.

## [필수 제약사항 — 위반 불가 규칙]

> 아래 규칙은 선택이 아닌 필수입니다. 생성 전 반드시 확인하세요.

1. **슬라이드 경계 준수** — 모든 콘텐츠는 슬라이드 영역 밖으로 절대 넘어가지 않습니다. 각 슬라이드 컨테이너에 `overflow: hidden` 필수 적용. 콘텐츠가 넘칠 경우 글자 크기·간격·카드 크기를 줄여 맞추세요.
2. **공통 슬라이드 구조** — 표지·섹션 전환 슬라이드를 제외한 모든 슬라이드에 **TOP BAR(56px) + CONTENT + FOOTER(40px)** 구조를 예외 없이 적용합니다.
3. **CSS 변수 전용** — 모든 색상·그림자·반경 값은 `:root`에 선언된 `var(--)` 변수만 사용합니다. 하드코딩 금지.
4. **iPhone 목업 필수** — 이미지를 사용하는 슬라이드는 반드시 **iPhone 14 Pro Max 목업 프레임**으로 감쌉니다. 프레임 내 이미지는 `object-fit: contain` 사용, `object-fit: cover` 사용 금지 (이미지 잘림 발생). 목업 크기: 1–2장 슬라이드 너비 300px, 3장 슬라이드 너비 260px.
5. **이미지 경로** — `/Users/csj200111/Desktop/졸작 페이지 사진 2/` 를 기본 경로로 사용합니다.
6. **다이어그램은 순수 HTML/CSS** — AI 파이프라인·시스템 아키텍처 슬라이드는 이미지 파일 없이 `div` + `flexbox`로만 구현합니다.
7. **장식 절제** — 과도한 그라디언트·그림자·애니메이션 금지. 여백·정렬·색상 대비로만 완성도를 높이세요.
8. **폰트 크기 최솟값** — 본문·포인트 항목 **24px(≈18pt) 미만 금지**, 캡션·라벨 **17px 미만 금지**, 다이어그램 내 텍스트 **15px 미만 금지**. 기업 발표자료 표준(18pt body)을 준수하여 프로젝터·대형 화면 가독성을 보장합니다.

### AI 파이프라인 상세 (2-Stage)

**처리 흐름**:
1. 이미지 정규화: RGB 변환 → 1280px 이하 리사이즈 → JPEG 95% 저장
2. Stage 1 — YOLOv8n 물품 탐지: broken/scratch 박스 제외, 물품 bbox 추출
3. Stage 2 — YOLOv8s-cls 손상 분류: bbox 크롭 이미지를 normal/scratch/broken으로 분류
4. 합산 확률 판정: YOLOv8s-cls 단일 모델에서 나온 broken_prob + scratch_prob ≥ 0.4 이면 손상, 미만이면 top1 클래스 사용 (※ "두 AI"가 합산하는 것이 아닌 하나의 AI 모델에서 나온 두 확률값을 합산)
5. Flask 응답: predictions[] (물품 목록) + damage (가장 심한 손상 집계)
6. Spring 백엔드 처리: 영문 클래스명 → 한국어 변환(WasteNameMapper), 손상 3단계 결정

**손상 3단계 (DamageLevel.java)**:
- NONE: 손상 없음 (null / normal) → 나눔 가능
- MINOR: scratch → 나눔 가능
- SEVERE: broken → 나눔 불가 (배출 권장)
